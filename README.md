# Titanic Survival Prediction

## Project Overview
Titanic Survival Prediction is a machine learning project based on the famous Titanic dataset. The objective of this project is to analyze passenger information and predict whether a passenger survived the Titanic disaster using machine learning techniques.

## Objectives
- Perform data cleaning and preprocessing.
- Analyze passenger demographics and survival patterns.
- Conduct Exploratory Data Analysis (EDA).
- Identify important features affecting survival.
- Build and evaluate machine learning models for survival prediction.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Handling Missing Values
4. Exploratory Data Analysis (EDA)
5. Feature Engineering
6. Model Training
7. Model Evaluation

## Machine Learning Models Used
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## Key Analysis Performed
- Survival rate analysis based on gender, age, and passenger class.
- Visualization of survival patterns using charts.
- Feature importance analysis.

## Results
The model predicts passenger survival based on historical Titanic passenger data and provides insights into the factors that influenced survival.
